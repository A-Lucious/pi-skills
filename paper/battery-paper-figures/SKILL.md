# 电芯论文插图绘制规范

配套 skill：`battery-paper-style` 管**文字**，本 skill 管**图**。写作时引用图后必须给读图结论，
该要求由 `battery-paper-style` 规定；本 skill 只负责把图本身画对。

## 0. 第一性原理：编排优先于配色

目标不是"画一张信息量很大的图"，而是**先画出若干幅各自成立的小图，再靠版式拼成大图**。

参考论文（Energy Storage Materials 86 (2026) 104947）的每一幅图都是这么来的：
小图本身干净、只讲一件事；大图的精致感来自**等尺寸、统一间距、留白分区**，不来自单张图的复杂度。

因此动手顺序固定为：

1. 先定这张大图要讲几件事 → 拆成几个面板，每个面板一件事。
2. 定版式：一个横幅面板 + N×M 等尺寸网格 + 底部图例条（这是主力版式）。
3. 用 `figstyle.compose_grid()` 生成画布——**面板尺寸是输入，画布尺寸是输出**，不要反过来。
4. 再往面板里填内容，用下面的元素库。
5. 最后统一检查（第 5 节）。

## 0.1 复现一张参考图的工作流：先量，后画，再对差

凭肉眼估参数一定会错。**用图像看坐标是不可靠的**——把渲染图显示出来后目测某个元素的位置，
误差可以到两倍。凡是要精确的地方，一律用脚本量像素。

固定循环，至少跑两轮：

1. **量原图**：`scripts/measure_figure.py` 取框架行、脊线列、柱状矩形（换算回数据单位）、
   文本墨迹高度、实际 RGB。再按需用连通域（`scipy.ndimage.label`）和颜色掩膜定位单个元素——
   文字、标记、箭头各是哪个方块，一目了然。
2. **定参数**：把测量值换算成绘图参数。换算时想清楚单位：墨迹高度 → 字号；帧线宽度 → linewidth；
   色块尺寸 → `handlelength` / `handleheight`。
3. **画**：用 `compose_grid()`，面板尺寸是输入。
4. **量自己**：对刚画出的图跑同一个测量脚本，逐项与原图对差。
5. **改**：只改差值最大的那几项，重跑第 4 步。

判断"对齐了"的标准是数字，不是观感：框架行列差 ≤1 px、柱位差 ≤1% 面板宽度、文本行位置差 ≤2 px。
做不到就继续第 5 步。

三件事必须写进脚本注释，否则下一轮会重犯：**每个参数从哪来**（哪个面板、哪个元素测的）、
**哪些值是逐组目视读出的近似值**（这些不要假装精确）、**哪些是对原图的主动偏离**（例如原图漏量纲）。

## 1. 版式规则（不可违背）

| 规则 | 做法 |
| --- | --- |
| 面板一律等尺寸 | 全图只有一种面板尺寸；`compose_grid` 由面板尺寸反推画布 |
| 横幅面板与网格面板等高 | `banner_ratio=1.0`；横幅不是压扁的标题条 |
| 行间距为面板下方标签预留 | 行间距要容下刻度文字 + 分组标签，两者都不许压到数据区 |
| 图例有独立条带 | 全图一个图例，放底部预留条带；只在横幅面板内部允许再加一个无边框图例 |
| 面板字母在坐标区外侧 | `(a)`…`(g)` 粗体、小写、带括号、统一偏移 |
| 面板只有一种尺寸比例 | 散点用近似正方形、柱状用 1.1–1.5 宽高比，同类面板必须一致 |
| 图例锚在网格中心 | 左右页边距不等时，锚画布中心会把图例推出 40 px |
| 页边距写进画布尺寸 | 由面板尺寸 + 间距 + 边距反推；存图关掉 `bbox_inches='tight'` |
| 坐标框近黑、刻度近黑 | 浅灰边框印出来等于没有框 |

实测几何（Fig. 6，300 dpi 量取）见 `references/style-reference.md`：面板 1.703 × 1.490 in、
列间距 0.637 in、行间距 0.587 in、横幅与网格面板等高、画布 7.37 × 6.55 in。

## 2. 字体与配色

- 全局无衬线（Arial）；字重只靠"粗体 / 常规"两档区分，不靠字号堆叠。
- 轴标签带单位括号；科学计数法**并进轴标签**（`MAE / RMSE (×10⁻³ Ah)`），
  不放坐标区左上角的浮动角标——浮动角标必与第一个面板内标注打架（见 3.1）。
- **一个变量占一个色相阶梯**：蓝色阶梯给主方法、红色阶梯给对照，
  同一个量（如 RMSE）在全部面板里始终是同一个颜色。
- 配色常量见 `scripts/figstyle.py` 顶部的 `BLUE` / `RED` / `GREY` / `GREEN_WASH`。

### 2.1 已经踩过的坑（逐条对应一次真实的返工）

**坑一：字体族参数只认通用名。** `matplotlib.rcParams["font.family"]` 的合法值是
`sans-serif` / `serif`，写成 `sans` 不会报错，会**静默回退到 DejaVu Sans**，于是"字体一直不对"。
`apply_style()` 里已做映射，不要绕过它直接设 `font.family`。

**坑二：柱偏移量是柱中心，不是左边界。** `matplotlib.bar(x, h, w)` 的 `x` 是中心。
本轮把实测的柱左边界直接当中心用，全部柱子整体偏了半个柱宽，肉眼几乎看不出来。

**坑三：边框要接近黑色。** 参考图的坐标框实测约 `#0E0E0E`、0.45 pt 细线，刻度文字近黑且分类标签为粗体。
用浅灰 `#D2D2D2` 画框，印出来等于没有框。

**坑四：字号必须按物理尺寸反推，不能凭感觉。** 把参考图按同一物理比例重采样后量取墨迹高度：

| 文本 | 参考图墨迹高 | 对应字号 |
| --- | ---: | ---: |
| x 轴刻度标签（`EN-CNN`） | 17 px @200 dpi | ≈ 9.0 pt |
| `•—— [10,50,100] ——•` 分组标签 | 22 px | ≈ 9.4 pt（粗体） |
| 图例文字 | 与刻度同档 | ≈ 8.8 pt |

对应 `apply_style(base_font=9.4)`。**图例条带比面板刻度更容易做小**：
参考图的图例是带细边框的方框，内有实心方块句柄，极易被画成"没有边框的一行小字"。
务必检查图例有边框、句柄有实体、`R²` 的虚线手柄足够长。

**坑五：图例要逐件量，不能整体估。** 原图图例实测：`MAE` 是**三个**色块共用一个标签
（每个模型一色，用 `HandlerTuple` 画在同一行；元组句柄必须显式传 `labels=`）；
`RMSE` 是 78×14 px 长条；`R²` 的手柄是"虚线穿三角"，长 131 px。
对应 `handlelength=3.12`、`handleheight=0.71`、`pad=0.15`。少一个色块就是 27% 的宽度差，
一眼能看出来。

**坑六：图例锚在网格中心，不是画布中心。** 左右页边距不相等时，`bbox_to_anchor=(0.5, y)`
会把图例整体推出 40 px。取中列面板的 `get_position()` 算网格中心。

**坑七：`bbox_inches='tight'` 会吃掉刻意留的页边距。** 复现原图时按需求解画布尺寸，
存图前要 `plt.rcParams["savefig.bbox"] = None`，否则顶部留白被裁掉、与原图错位。

**坑八：面板内的文字、标记、箭头必须互不压盖。** 见第 3.1 节。

## 3. 面板内元素库

`scripts/figstyle.py` 里每个函数对应参考图的一个标志性元素：

| 元素 | 函数 |
| --- | --- |
| 面板字母 | `panel_label` |
| 细边框 / 开放式轴框 | `boxed_frame` / `open_frame` |
| 高亮底色带 | `highlight_band` |
| `×10⁻³` 角标 | `offset_text` |
| 面板内指标文字块 | `metric_block` |
| `•—— [10,50,100] ——•` 分组标签 | `group_axis_label` |
| 双向箭头跨度标注 | `span_arrow` |
| 红色弧形箭头 + 粗体百分比 | `value_arrow` |
| 直线引导箭头标注极值 | `point_arrow` |
| 虚线参考线 / 对角线 | `dashed_guides` / `identity_line` |
| 虚线 + 空心三角 + 百分比（R²） | `r2_overlay` |
| 面板内嵌小色条 | `inset_colorbar` |
| 气泡矩阵（大小 + 颜色编码） | `bubble_matrix` |
| 全图横向图例 | `figure_legend` |

### 3.1 面板内标注不许互相压盖（实测规则）

信息密度高的面板最容易出这类问题，且**渲染图缩到正文尺寸后更难发现**。四条硬规则：

1. **百分比/数值标签跟随标记，但最高点自动下移。** 原图里最高那个标记的标签在标记**下方**，
   其余在上方。`r2_overlay()` 已内置该判断；自己在别处加标签时照此处理。
2. **箭头终点避开标记的横坐标。** 弧线箭头若指向柱心，箭头会正扎进上方的三角标记。
   实测做法是落在柱**顶左角**。
3. **角标不进坐标区。** 原图柱状面板内**没有** `×10⁻³` 这类浮动角标——量纲写在轴标签里。
   若沿用浮动角标，它会和左上角第一个标注打架。
4. **重叠要量出来，不能只靠看。** 用连通域列出区域内所有墨迹块的外接框，两两判交。
   同一面板内任意两个外接框相交即为违规，必须挪。

## 4. 怎么用

```python
import figstyle as fx

fx.apply_style(family="sans")          # 全篇只调一次，勿混用 serif
layout = fx.compose_grid(
    width="full",                      # 190 mm 正文宽
    nrows=2, ncols=3,
    panel_ratio=1.143,                 # 面板宽/高，等于参考图实测值
    banner_ratio=1.0,                  # 横幅与网格面板等高
    hspace_in=0.587, wspace_frac=0.374,
    strip_in=0.28,                     # 底部图例条带
)
fx.panel_label(layout.axes[0, 0], "b")

# 图例：一个量一个色阶，多色共用一个标签时用元组句柄；锚点取网格中心
handles = [tuple(fx.patch_handle(c, "MAE") for c in MODEL_COLORS),
           fx.patch_handle(fx.RED["pale"], "RMSE")]
mid = layout.axes[0, 1].get_position()
fig.legend(handles, ["MAE", "RMSE"], loc="center",
           bbox_to_anchor=(mid.x0 + mid.width / 2, y),
           handler_map={tuple: HandlerTuple(ndivide=None, pad=0.15)})

# 面板内标注：最高点的标签自动下移，箭头落柱顶左角
fx.r2_overlay(ax, x, r2_percent, band=(0.74, 0.955), dy_text=0.045)
fx.value_arrow(ax, "40%", xy_text=(-0.10, 0.45 * ymax),
               xy_point=(1.0 + RMSE_OFFSET - BAR_WIDTH / 2.0, rmse))
```

**复现范例**：`scripts/fig6_reproduction.py` 是对参考论文 Fig. 6 的近乎像素级复现，
涵盖上面每一个元素。改动样式后先跑它，与原图并排比对。参数不要靠眼睛估：用 `scripts/measure_figure.py` 量原图，再量自己画出的图，逐项对差。

```bash
python scripts/fig6_reproduction.py        # 输出 fig6_reproduction.png / .pdf
python scripts/demo_figstyle.py            # 元素总览，用于快速自查
python scripts/measure_figure.py --help    # 从已发表图上反算子图参数
```

`fig6_reproduction.py` 顶部的数字是**从已发表图上逐格读出的**，只用于让复现图能和原图叠对比对，
属于本项目的电池数据，严禁当成本项目结果引用。

## 5. 交付与自查

- 画布宽度对齐正文宽（190 mm）。用 `compose_grid` 时面板尺寸已知，不要再靠 `tight_layout` 救火。
- 同时导出 PNG（≥ 400 dpi）与矢量大 PDF。
- 图题按 `battery-paper-style` 的规范写：名词短语 + 面板罗列 + 读图必要信息，**不设独立图注行**。
- 交稿前逐条过：

- [ ] 全图是否只有一种面板尺寸？
- [ ] 横幅面板是否与网格面板等高？
- [ ] 行间距是否容下了刻度与分组标签，没有压到数据？
- [ ] 图例是否只有一套、放在独立条带里？是否锚在**网格中心**？
- [ ] 图例是否逐件量过：色块个数、色块尺寸、`R²` 手柄长度，都与参考图一致？
- [ ] 面板字母是否都在坐标区外侧、偏移一致？
- [ ] 同一个量在不同面板里是否还是同一个颜色？
- [ ] 每个面板内，用连通域列出的墨迹块是否有相交的？（文字、标记、箭头、角标）
- [ ] 坐标框是否为近黑细线，刻度文字是否近黑、分类标签是否粗体？
- [ ] 存图是否关掉了 `bbox_inches='tight'`，保留刻意留出的页边距？
- [ ] 脚本注释是否写明了每个参数的来源、哪些是目视近似值、哪些是主动偏离？
- [ ] 是否出现了 `jet`、彩虹分类色、满屏网格线、面板内重复图例？
- [ ] 有没有把 `fig6_reproduction.py` 里的示意数字当成真实结果？

## 6. 事实边界

- 复现范例里的数值来自已发表论文，只可用于风格比对与版式校准。
- 本项目自己的图上只允许出现本项目数据；没有验证过的趋势、拐点、单调性一律不画，
  只画数据支持的区间、范围与差异。
- 项目已有的 `scripts/plot_figure3_dataset_overview.py`、`scripts/plot_figure4_split_schemes.py`
  使用 Times 衬线体；新图统一用本 skill 的无衬线体系，并把旧图一并改字体，全篇不得混排。
