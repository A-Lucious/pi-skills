# 参考论文图形语言实测记录

样本：`1-s2.0-S2405829726000802-main.pdf`，Energy Storage Materials 86 (2026) 104947。
下列数值均由该 PDF 实测（300 dpi 光栅化后量取），不是印象描述。

## 1. 编排（最重要的一条）

作者不画"一张信息量很大的图"，而是**先画出若干各自成立的小图，再靠版式拼成大图**。

Fig. 6 是一个典型：横幅框图的箱线总览 + 2×3 等尺寸柱状网格 + 底部独立图例条。

实测几何（300 dpi，像素 ÷ 300 = 英寸）：

| 单个网格面板宽 | 511 | 1.703 |
| 单个网格面板高 | 447 | 1.490 |
| 横幅面板高 | 447 | 1.490 |
| 列间距 | 191 | 0.637 |

### 1.1 子图级实测参数（`scripts/measure_figure.py` 反算）

| 量 | 实测值 | 对应代码 |

### 1.3 面板内标注的排布规则（逐像素核对得出）

| 结论 | 依据 |
| --- | --- |
| 柱状面板坐标区内**没有** `×10⁻³` 角标 | 连通域分析：面板 (b) 内最靠上的墨迹是第一个三角标记（y=468），其上方空白 |
| 量纲写进轴标签 | 复现时改为 `MAE / RMSE (×10⁻³ Ah)`，既消除与首个百分比的碰撞，也不丢单位 |
| 三角标记位于坐标区高度 0.86–0.96 的窄带内 | 六面板实测三角顶点：57.2/57.6/72.2/57.0/73.2/73.0（对应量程 60 或 75） |
| 最高那个百分号标签放在标记**下方**，其余在**上方** | 原图 `98.91%` 墨迹 y 501–519，其三角 y 468–486 |
| 弧形箭头终点取柱顶左角，不取柱心 | 取柱心时箭头会正好压住上方的三角标记 |

`r2_overlay()` 已内置"最高点标签自动下移"的规则，`value_arrow()` 的终点需显式避开标记的横坐标。

结论，落到参数上：

1. **横幅面板与网格面板等高**（banner_ratio = 1.00）。横幅不是"压扁的标题条"。
2. **面板一律等尺寸**，宽高比 511/447 = 1.143。全图只有一种面板尺寸。
3. **行间距 0.587 in 是为面板下方的标签留的**：容纳 x 轴刻度 + `•—— [10,50,100] ——•` 分组标签，
   两者都不许压到数据区。
4. **底部 0.727 in 单独留给图例**，图例有独立条带，不塞进任何面板内部。
5. 全图只有一个图例；只有横幅面板内部另有一个无边框的模型图例。

## 2. 字体

- 无衬线（Arial / Helvetica 一系）。全图无衬线，无衬线/衬线混排。
- 面板字母 `(a)`…`(g)` 粗体、小写、带括号，位于坐标区**外侧**左上角，偏移量统一。
- 粗体只用于：面板字母、面板内标题、分组标签、百分比标注、图例文字。
- 轴标签与刻度为常规字重。坐标轴标签带单位括号：`MAE / RMSE (Ah)`、`|Error| (Ah)`。
- 科学计数法用独立的 `×10⁻³` 角标放在坐标区左上角，不写进刻度数字。

## 3. 配色（十六进制取自图内实测）

| 角色 | 值 |
| --- | --- |
| 主方法（EN-CNN） | `#104680` |
| 对照（RE-CNN） | `#4B73A0` |
| 对照（EXP） | `#6D011F` |
| RMSE 统一色 | `#F6B293` |
| 高亮底色（面板右侧） | `#F6B293`，约 22% 透明度 |
| 轴框 / 网格 | `#D2D2D2` / `#EBEBEB` |
| 正文文字 | `#3E3E3E` |

规律：**一个变量占一个色相阶梯**。蓝色阶梯给方法，红色阶梯给对照；
同一个量（RMSE）在六个面板里始终是同一个鲑鱼色，不随面板改变。

## 4. 图例

- 底部一个带细边框的横向图例，3 组：`MAE` / `RMSE` / `R²`。
- `MAE` 用**两枚色块共用一个标签**表示"MAE 取各自模型色"，实现用
  `matplotlib.legend_handler.HandlerTuple`（注意：元组句柄必须显式传 `labels=`）。
- `R²` 的句柄是"虚线 + 空心三角"的组合句柄。
- 横幅面板内的模型图例无边框，右上角，横排。

## 5. 面板内的高信息密度元素

- **虚线 + 空心三角 + 百分比标签**：R² 曲线压在柱状之上，映射到坐标区上部 68%–90% 高度带，
  不与柱顶冲突。
- **红色弧形箭头 + 粗体百分比**：从面板左下指向被强调的柱顶。
- **`•—— [10,50,100] ——•` 分组标签**：线两端各一个实心圆点，标签压在线上（白底断开线条），
  位于坐标区下方，替代常规刻度标签。
- **面板内粗体标题**：`All batteries in Subset-A (with 72)`，左上角。
