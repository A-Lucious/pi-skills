## 2. 工作流（四步，且只花几百行上下文）

**第 1 步 定范例与语体。** 英文稿：写实验/数据集章节，直接用主范例 138–162 行；写其他主题，用第 3 节的检索配方在 `SOT papers_txt/` 里定位 1–2 篇。中文稿：先按 4.3 节定语体（期刊论文体 / 基金申请书体 / 开题报告体 / 汇报体），再按 1.2 节坐标到 `references/zh-corpus.md` 取对应句库；一份稿子只用一种语体。

**第 2 步 抽骨架。** 只读目标区间（20–40 行），把句子拆成"槽位"：
`[对象] + [做了什么] + [数字] + [图/表引用] + [一句读图结论]`。

**第 3 步 填空。** 用第 9 节的项目事实替换槽位。数字必须来自项目数据或已复算结果，不沿用范例数字。

**第 4 步 先英文，后中文。** 先写成符合 Elsevier 体例的英文句，再译成通顺的中文论文语言。
中文不得是英文的直译，不得出现统计与代码黑话；同一概念在全文只用一个中文写法。

## 4. 风格规则

### 4.1 英文（Applied Energy / J. Energy Storage 体例）

1. **段落极短**，每段 1–3 句，一句推进一步。主范例中整个 Section 2 只有 15 句。
2. **句子顺序固定**：先陈述做法或现象，再给数字，最后一句解释或指向图表。
   - `As shown in Table 4, 15 cases (total data number: 141,901) are used for training and the remaining 3 cases for testing.`
3. **客观主语与被动为主**，方法部分才用 we：`we adopt the VRLS`、`we employ LSTM`；结果部分一律 `is shown / is found / is exhibited / it can be found`。
4. **数字紧贴单位，不加修饰**：`0.3339 °C`、`390 s`、`25 °C`；结论只给量级：`the MAEs ... can be <0.5 °C`。
5. **图表驱动**：几乎每段至少一处 `Fig. x` / `Table x`，且引用后必须给出从图中读到的结论。
6. **连接词固定**：`However`、`Therefore`、`Afterwards`、`Based on the analysis`、`This indicates that`、`It is found that`。
7. **只写做了什么**，不写"我们不使用/禁止/不做"。全篇找不到 `we do not`。
8. **标题用名词短语**：`2. Experiments`、`4.1. Parameter smoothing`、`4.3. Input time length of the DNN model`。

### 4.2 中文手稿（与英文一一对应）

- 一段一事实，段末挂图或表："……列于表 2""……如图 3 所示"。
- 数量词前置，单位紧跟："共 2,355 个完整循环""平均绝对误差为 0.216 °C"。
- 引用图后必须给出读图结论："由图 3(a) 可见，8 个通道的完整循环数处于 279–320 之间"。
- 结论句克制："结果表明……""由此……"，不用"极大地""显著地"堆叠。
- 一律写"循环"，不写 `cycle`。
- 不用"折"作量词搭配（不写"8 个折"）：本项目的 E1–E4 不是 K 折交叉验证，统一写"N 组划分"；
  若确需 fold，须先定义"一次完整的训练—验证—测试划分为一折"，后文写"共 8 折"。
- 不用"派生"（不写"派生窗口"），写"由同一循环生成的窗口"或"同一循环的滑动窗口"。
- **只用肯定陈述句**。禁止出现"不 / 未 / 无 / 禁止 / 不得 / 尚未 / 而是"式说明；
  需要划清范围时，改为说明事物的归属或用途。全段读下来应句句自信、句句陈述。
  - 误："不使用环境温度序列" → 正："热边界取测试计划规定的室温约 25 °C"
  - 误："禁止随机行切分" → 正："数据集以完整循环为单位按时间顺序划分"
  - 误："测试期不读取未来数据" → 正："时刻 t 的输入由 t 及 t 之前已到达的样本递推得到"
  - 误："同一循环及其滑动窗口不跨集合" → 正："同一循环及其滑动窗口归入同一集合"
  - 误："该段误差不计入上述指标，而是用于确定收敛时间" → 正："起始处第一个窗口的误差用于确定收敛时间"
  - 误："其余环节不属于常规运行过程" → 正："其余环节作为压力测试工况单独统计"
  - 误："E2 中被留出的通道不参与训练" → 正："E2 留出整个通道的全部循环用于测试"
  - 误："实验尚未到达 80% 截止条件" → 正："截至本文数据截取时，各通道末段循环的容量保持率为 89%–92%"
  - 误："表中不列温度下限" → 正："表中温度取各循环的最高表面温度"
- **否定句边界**（据中文语料修订）：指向"已有研究的空白或客观条件限制"的否定可用，指向"本文自己做了什么"的否定一律改为肯定陈述。
  允许的三处：① 研究空白（`目前针对……研究较少`、`未能建立……，限制了机理解释`、`仍没有明确的结论`），须给出具体缺口与出处，并紧跟"因此，……十分重要"；
  ② 局限性节（`由于实验条件限制，本文并未开展……，未来将……`）；③ 对照方法的客观限制（`但其离子电导率较低，也会导致……急剧下降`）。
  句式与坐标见 `references/zh-corpus.md` 第 5 节。

## 6. 表与图的交付规范

**表**
- 交付时必须填真实数据，不留空格或"xx"。
- 每张表配一句表注，说明数值的取值方式（如"电流范围取循环级统计量的极值"）。
- 表题用名词短语：`表 2 通道分组与数据规模`。
- 合计行放在末行并加粗。

**图**
- 该刊体例只有图题（`Fig. n. ...`），**不设独立图注行**；所有说明压进图题内。
  - 图题 = 名词短语 + 面板罗列 + 必要的读图信息（每个点代表什么、横轴含义、双轴各自的量与单位、颜色与纹样对应的类别）：
    `图 4 四种划分方式示意。(a) E1；(b) E2；(c) E3；(d) E4。每条横轴为一个通道按时间排列的完整循环序列，深色、浅色与斜纹分别对应训练集、验证集与测试集，灰色为该组中留出的循环。`
  - 数据来源与素材文件名只在**交付给作者的说明**里列出，不进正文。
- 表注可以有，但形式为紧跟表题的括号短句：`表 2 通道分组与数据规模（电流范围与最高表面温度取各通道循环级统计量的极值）`；
  参照范例 `Table 4 ... (Boldface: testing data; Others: training data.)`。
- 优先复用已有素材（`manuscript_assets/fig*.png`），缺素材时说明面板如何生成。
- 不得虚构图中趋势：没有验证过的单调性、拐点、分组差异一律不写；只写数据支持的区间、范围与差异。

**正文与图的关系**
- 引用图后必须给出一句读图结论，不能只挂图不解读。
- 表与图分工：精确数值进表，分布与随时间的变化进图。

## 7. 句库（按槽位取用）

**数据集段**
- `The eight channels are divided into three groups according to the discharge protocol, namely high-power dynamic discharge (channels 1–4), mixed-power dynamic discharge (channels 5–6), and constant-power discharge (channels 7–8), as listed in Table 2.`
- `Fig. 3(a) shows that the number of complete cycles of the eight channels lies between 279 and 320.`
- 中文：`8 个通道按放电协议分为三组，即高功率动态放电（通道 1–4）、混合功率动态放电（通道 5–6）与恒功率放电（通道 7–8），如表 2 所列。`

**测试计划段**
- `The dataset is divided into training, validation, and test sets in units of complete cycles along the time axis, and the windows generated from one cycle stay within the same set.`
- `E1 is applied to each channel separately, taking the first 60% of the cycles for training, the middle 20% for validation, and the last 20% for testing, which gives eight divisions.`
- 中文：`E1 对每个通道分别建立一组划分，取前 60% 的循环训练、中间 20% 验证、后 20% 测试，共 8 组。`
- 中文：`四种划分合计 23 组，训练、验证与测试的记录行数分别为 14,800、4,951 与 5,413。`

**指标段**（极简，主范例没有独立指标节，只是随用随定义）
- `The estimation error is evaluated on each step of each test cycle and is then averaged over the 23 divisions with equal weight.`
- `The maximum absolute error is reported alongside them.`

## 8. 术语与命名规范

- 表面温度 `T1` / `Ts`，内部温度 `Tin`，环境温度 `Ta`；`T1` 不得写成核心温度或体平均温度。
- 容量保持率须注明基准（相对标称容量或相对首次 RPT 容量）；出现 >100% 的读数时说明其取自何种基准，不直接称作 SOH。
- 不用"口径"一词：`评分口径` → 评分方法 / 同一套指标；`统计口径` → 取值方式；`聚合口径` → 聚合方式；
  `降低口径` → 改写陈述，直接给出实际数值区间。
- 误差单位统一 `°C`。正文只定义并报告四个量：平均绝对误差、均方根误差、偏差、最大绝对误差；`P95` 只出现在表头。
- 聚合方式写作"对各组划分取等权平均"（英文 `averaged over the divisions with equal weight`），并说明先在"通道—循环—工步阶段"上计算；不写"fold 宏平均""各折等权平均"。
- **同一句话里不重复限定词**：聚合方式在段首交代一次即可，后文只写"平均绝对误差"，不再叠加"23 组划分等权平均后的平均绝对误差"。
- 划分方式与评分方法属**所有方法共用**，写在实验章；仅本文模型使用的特征构造（1 Hz 网格、SOC 代理、EMA、RLS 状态、归一化、窗口）写在方法章。
- 不得进入正文的自造工程词：`因果`（正文写"只用当前及历史样本"）、`原子`（写"以完整循环为单位"）、`信息边界`（写具体规则）。
- 脚本字段与内部编号不进正文，首次出现时给一次中文定义后统一使用：
  `#1–#4` → 通道 1–4（`channels 1–4`）；`fold 宏平均` → 各折等权平均；
  `channel-cycle-stage` → 通道—循环—工步阶段；`no_event` → 不含事件分支的配置；`ui_only` → 仅电压电流输入；
  `r0_estimate` → 有效端口内阻 \(r_0\)；`Flash / RAM` → 模型存储占用 / 运行内存占用。
- 统计黑话不进正文：`95 分位` → 只在表格中出现时写"绝对误差的 95% 分位数"，正文优先写"最大绝对误差"；
  `尾部偏差` → 改写为"最大绝对误差一并给出"。
- 工程缩略词写完整：`主工况` / `主部署工况` → 主要运行工况（英文 `main operating condition`）；
  `压力测试工况` 保留，但首次出现时说明其含义为"非主要运行工况的检验环节"。
- 公式交付三件套：① 可渲染的 `\[ ... \]`（编号写 `\qquad (1)`，不用 `\tag{}`）；
  ② 可直接粘贴的 LaTeX 源码块（MathType / Word 公式编辑器用）；③ 不依赖渲染的纯文本形式。
  MathType 用法：开启 TeX 输入后，把源码粘进公式窗口即可转换；编号 (1) 建议用 Word 的题注或右侧编号列，
  源码里保留 `\qquad (1)` 仅用于预览。
- **中文电池术语**首次出现给中英全称：`放电深度(depth of discharge，DOD)`、`荷电状态(state of charge，SOC)`、
  `电化学阻抗谱(electrochemical impedance spectroscopy，EIS)`、`内短路(internal short circuit，ISC)`、
  `热失控(thermal runaway，TR)`。完整对照表（预紧力、膨胀力、扩散诱导应力、固-固界面、原位/非原位、拆解分析、
  唯象模型、响应面、帕累托前沿等）见 `references/zh-corpus.md` 4.1 节。
- 中文稿图题中英双语、子图用 `(a)(b)(c)`、正文引用写 `图 5(d)`；符号说明表格式为 `符号—— 含义，单位`。

## 12. 公式源码清单（累计，避免重复生成）

**公式 (1)** 平均绝对误差、均方根误差与偏差（2.4 节）

```latex
\mathrm{MAE}=\frac{1}{N}\sum_{j=1}^{N}\left| \hat{T}_{1,j}-T_{1,j}\right| ,\quad \mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_{j=1}^{N}\left( \hat{T}_{1,j}-T_{1,j}\right) ^{2}} ,\quad \mathrm{bias}=\frac{1}{N}\sum_{j=1}^{N}\left( \hat{T}_{1,j}-T_{1,j}\right)
```

拆成三行单独使用时：

```latex
\mathrm{MAE}=\frac{1}{N}\sum_{j=1}^{N}\left| \hat{T}_{1,j}-T_{1,j}\right|
\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_{j=1}^{N}\left( \hat{T}_{1,j}-T_{1,j}\right) ^{2}}
\mathrm{bias}=\frac{1}{N}\sum_{j=1}^{N}\left( \hat{T}_{1,j}-T_{1,j}\right)
```
